# RedeemStore - Flat 2% Instant Discount Platform

Online redeem code store jahan users 2% discount par cards purchase kar sakte hain aur UPI se pay kar sakte hain.

## Features
- 10 Sleek Debit Card Style Denominations (₹100 se ₹1000)
- Auto 2% Discount Calculation
- Dynamic UPI QR Code Generation
- Password-Protected Live Admin Panel (PIN: 809047)
- Instant Payment Approval & 1-Hour Delivery Countdown Timer
- Direct WhatsApp Integration

## Tech Stack
- **Backend:** Python (Flask, Gunicorn)
- **Frontend:** HTML5, Tailwind CSS, JavaScript
- **Deployment:** Render.com

## How to Run Locally
```bash
pip install -r requirements.txt
python main.py
